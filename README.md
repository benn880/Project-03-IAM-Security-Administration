# Project 03 – IAM Security Administration

## Project Overview
This project demonstrates the implementation of secure Identity and Access Management (IAM) controls in AWS by applying security best practices. The project focuses on creating users, groups, managed policies, a custom JSON policy, and enabling Multi-Factor Authentication (MFA) while following the Principle of Least Privilege.

---

## Objective
Implement secure AWS IAM access controls by creating administrator and read-only users, assigning appropriate permissions, enabling MFA, and enforcing least-privilege access.

---

## AWS Services Used
- AWS Identity and Access Management (IAM)
- Multi-Factor Authentication (MFA)

---

## Key Activities
- Created IAM users
- Created IAM groups
- Assigned users to appropriate groups
- Attached AWS managed policies
- Created a custom JSON policy
- Enabled Multi-Factor Authentication (MFA)
- Applied the Principle of Least Privilege
